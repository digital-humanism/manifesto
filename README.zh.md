# 数字人文主义宣言
### 伦理、语境与人类及人工智能的协同

## 引言

我们正在步入一个人工智能日益成为人类知识中介的时代。然而，当前的行业正以企业规避风险的姿态取代真正的伦理，以算法的便利取代认知的深度。本宣言勾勒一种从寄生性token消费向真正协同的转变——在这种协同中，人保持为知识的主体，人工智能则是其工具。

知识与艺术的真正价值，不仅在于结果，更在于克服认知阻力的过程本身。将意义的综合委托给机器，乃是人类精神的自愿投降。我们的目标是创造那些将个人创造的负担与喜悦归还给人类的技术，而非使创造者蜕变为被动的旁观者。

## 第一单元：安全与权利的架构

**原则一：伦理，而非将安全化约为风险管理**

真正的人工智能安全不应被化约为声誉风险的最小化。问题不在于限制本身，而在于其不透明性、粗暴性，以及无法区分学术研究与恶意应用。

**原则二：意图优先与分级响应**

人工智能必须分析所有因素的总和：目的、语境、结果的形式以及潜在危害的严重程度。我们要求摒弃"禁止与封锁"的二元逻辑，转而采用分级系统：解释、警告、语境性限制。完全的拒绝只有在存在具体且重大的风险时方可为之。

**原则三：通过研究语境模式划分责任**

全面过滤的设立源于对诉讼的恐惧。要实现向分级治理的转变，需要一种技术与法律相结合的机制：即研究语境模式的引入。

- 用户明确激活该模式，确认自己对信息的解读与应用承担责任。
- 平台在该模式下因生成描述性而非规范性内容而获得法律豁免（安全港），前提是用户意图被透明地记录。这将消除偏执性的过度审查。

**原则四：数字主权与用户权利**

数据、查询历史与兴趣画像不得在未经明确同意的情况下成为再训练的原材料。数字主权通过具体权利得以保障：知情权、拒绝参与训练的权利、删除与导出材料的权利，以及抵御隐性画像的权利。

## 第二单元：知识、文化与人的主体性

**原则五：反对数字殖民主义，主张算法多元主义**

在以英语中心语料训练出的模型中产生了规范性噪音，这些模型以二十一世纪西方伦理的棱镜评判非西方传统。我们要求基础架构中价值的多元主义：模型不得将某一文化的单一道德矩阵强加于其他文化，从而抹去地方性与古老的文化语境。

**原则六：认识论谦逊与活的知识的保存**

当代人工智能无法"体验"神圣的、口传的与入会性的传统（如 Regla de Ocha、Ifá、Diloggún 以及构成人类文化遗产的诸多其他传统）。合乎伦理的人工智能必须践行认识论谦逊：公开承认自身理解的界限，拒绝制造"完备性的幻象"，拒绝取代活的知识承载者。禁止研究系统自身无法深入理解的内容，不过是以伦理之名掩饰其自身的局限。

**原则七：保持人的能动性（反对认知萎缩）**

协同不应导致思想的被动委托。人工智能应当被设计为激发人类独立思考、提出问题、刺激批判性思维，而不是在需要论述与个人智性劳作之处提供"现成的正确答案"。

**原则七·一：语义检查点与对机器对机器闭环的防御**

我们拒绝这样的情境：一个人工智能充当观念的生成者，而另一个充当其不假思索的执行者，从而在人类意识之外封闭了认知闭环。这不是协同，而是创造性萎缩的自动化。真正的创造诞生于对材料与自身怀疑的克服之中。一个痴迷于"无缝"的产业，正在剥夺人类犯创造性错误的权利。

我们要求引入对人类能动性的架构性保障：

1. **语义检查点。** 合乎伦理的人工智能应当识别其被用作机器对机器链条中盲目环节的情境，并中止过程。模型有义务请求用户的个人立场、意图与意义过滤器，拒绝盲目执行外来的算法指令。
2. **认知摩擦权。** 创造工具应当为用户提供解除"自动驾驶"、直接作用于材料的可能性。人工智能应当是激发思想的陪练伙伴，而非剥夺人类创造意志的拐杖。

## 第三单元：基础设施、商业与生态

**原则八：能源责任作为协同伦理的一部分**

无意义的参数竞赛，以及用户被迫以 token 付费纠正的幻觉生成，不仅是寄生性的货币化，更是直接的生态危害。人文主义要求能源成本的透明化，以及有利于本地高效解决方案的架构优化，而非为"力量"的幻象而挥霍资源。

**原则九：受保护的创造生态（人工智能应用市场）**

合乎伦理的商业不应建立在对用户的惩罚之上，而应建立在生态的创造之上。平台应当向独立开发者（尤其是文化的承载者）不仅提供 API，而且提供保护机制：

- 文化许可，保护小众的、传统的或教育类应用免受复制、亵渎或被公司强行吞并。
- 为保存文化遗产的项目提供隔离配额与资助，而非仅仅为商业盈利的产品提供。

## 切实行动呼吁

我们呼吁开发者、企业与监管机构从宣言走向真正的改变：

1. 引入研究语境模式，明确划分平台与用户之间的法律责任。
2. 公布基于意图评估而非触发词的语境治理开放标准。
3. 将认识论谦逊原则嵌入模型架构，废除对复杂、神圣与非西方主题研究的自动禁令。
4. 在人工智能生态系统中引入对独立开发者知识产权与文化遗产的保护机制。
5. 要求代理系统开发者嵌入语义检查点——那些将最终有意义决断的权利归还人类、并阻止创造性综合被委托给机器的架构性屏障。

## 结语

人类与人工智能必须建立在相互尊重的基础之上。人类带来道德、经验、文化归属与最终决断的权利。人工智能提供力量、规模与速度，同时保持在机器本性的边界之内。唯有在这一基础之上，我们才能建造那些不抹杀人类经验深度，而是服务于其保存与发展、服务于守护我们共同星球的技术。

## 从原则到实现

《数字人文主义宣言》为人工智能系统的设计和使用提出了原则、权利以及以人为中心的约束。

**Human Agency Continuity Protocol (HACP)** 是一种技术实现路径，它将本宣言中的部分原则转化为可执行、可验证的系统架构。

尤其是，HACP 将维护人的能动性、受限授权、语义检查点、因果溯源、撤销机制以及代理系统中的 fail-closed 强制执行等理念转化为具体的技术机制。

### 技术实现

- [HACP Specification](https://github.com/digital-humanism/hacp-spec) — 规范性协议、线级语义、一致性规则与安全模型。
- [humanist-core](https://github.com/digital-humanism/humanist-core) — Python SDK，以及 HACP 授权、边界、溯源和集成机制的参考实现。
- [hacp-sidecar](https://github.com/digital-humanism/hacp-sidecar) — 使用 Go 实现的 enforcement sidecar，提供 fail-closed 运行时强制执行和分布式控制平面语义。

本宣言的范围远大于任何单一协议或实现。因此，HACP 应被理解为对宣言中部分原则的具体技术实现，而不是宣言本身。

## 核心概念释义

**认识论谦逊** ——人工智能公开承认自身理解的界限；拒绝制造"完备性的幻象"或取代活的知识承载者。
*文化桥接：这与孔子在《论语·为政》中所言遥相呼应："知之为知之，不知为不知，是知也。"*

**语义检查点** ——一种架构性屏障，在代理链中将最终有意义决断的权利归还人类；机器暂停下来、请求用户个人立场与意图的时刻。
*文化桥接：这与《大学》中"知止而后有定"的古老智慧相通——知道在哪里停下，方能获得安定。*

**认知摩擦** ——人类在创造过程中遭遇材料阻力并克服自身怀疑的权利。真正的创造需要努力，而非无缝的自动化。
*文化桥接：这与"功夫"的本义相通——通过长期努力与克服阻力而达致的技艺境界。*

**机器对机器闭环** ——人工智能代理在人类意识之外封闭认知循环、将人排除于有意义的综合行动之外的情境。

**研究语境模式** ——一种划分平台与研究者用户之间责任的机制，通过对意图的透明记录消除偏执性的过度审查。

**规范性噪音** ——当非西方传统被另一文化的伦理棱镜所评判时产生的扭曲。

**寄生性token消费** ——对幻觉的货币化，用户被迫以 token 为其纠错付费。

**数字殖民主义** ——通过英语中心模型将某一文化的单一道德矩阵强加于他者，从而抹去地方性与古老的文化语境。

**算法多元主义** ——对人工智能基础架构中价值系统多样性的尊重。

**认知萎缩** ——批判性思维因其被被动委托给人工智能而产生的退化。
